# Catálogo de skills

## Producto (`AI/skills/`, canónicas)

| Skill | Trigger |
|---|---|
| `cf-cli` | antes del primer `cf` del turno |
| `btp-cli` | antes del primer `btp` del turno |
| `cap-cli` | antes de cualquier `cds` |
| `mta-build` | antes del primer build MTAR |
| `sap-verify` | ante afirmación sobre servicio/plan BTP |

## Globales (cargar por fase, no todas)

`sapui5` con `frontend-ui5`, `systematic-debugging` ante fallos,
`verification-before-completion` con `qa-review`,
`test-driven-development` si la spec exige TDD, `git-workflow` con git.
Externas SAP (`INICIO.md § Skills candidatas`) solo bajo demanda inspeccionada.

## Meta

Nuevas skills solo con necesidad real no cubierta; con propósito, criterios
de activación, flujo, herramientas y resultado. Sin duplicados.
